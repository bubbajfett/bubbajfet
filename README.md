
# Current guitar pedal projects

These pedals have been a learning exercise for me in KiCad.  Any guitar pedal
PCB published here has been built and tested.   In some cases, more than two versions
of boards have been created.

The main idea for doing my own PCB is to allow me to change the footprints
and merge and/or hack pedal schematics to come up with new ideas.    Unlike
other commercial guitar pedal PCB creators, I am an amateur in this.

Putting these pedal layouts out there for any interested party.   Creative commons licenses, 
so do whatever you like with these.

All have a gerbers/ subdir with the last gerber file I generated.    Using OshPark for pcb 
generation.   Also using JLCPCB for pcb generation.    Almost all of the project subdirectories
have a single PCB, though some have more than one.   There are about 2 dozen more 
that are being validated, as I am not wanting to put anything out there that I have not 
gotten to work.    That's not to say they are 100% perfect, but ...
